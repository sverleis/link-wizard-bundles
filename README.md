# Link Wizard for Bundles

WooCommerce Product Bundles integration for Link Wizard.

- Add-to-Cart URLs: full support using bundle form/query parameters.
- Checkout-Link URLs: default bundle only (no custom configuration), intended for discount-style bundles.

Repository: https://github.com/sverleis/link-wizard-bundles

## Status
Initial scaffold for code review.

## Requirements
- WordPress 6.2+
- WooCommerce 8.2+
- PHP 7.4+
- WooCommerce Product Bundles

## Roadmap
- REST endpoints to generate add-to-cart URLs for bundles.
- Admin UI to show bundled items and default/limits.
- Fallback checkout-link generator using default bundle configuration.
